# EKKAYI — Artisanal Luxury Furniture & Architectural Living

Welcome to **EKKAYI**, an artisanal luxury furniture and functional art platform featuring:
- **Interactive 3D Spherical Furniture Galaxy** powered by Three.js
- **Soft Parchment & Ekkayi Forest Green** brand aesthetic
- **Genuine Luxury Furniture Catalog** (Sofas, Sectionals, Recliners, Teak Dining Tables, Bedroom Suites, Credenzas)
- **High-Performance React App** built with Vite & TailwindCSS
- **Production-Ready Shopify Liquid Theme** (`ekkayi-shopify-theme.zip`)
- **Shopify Bulk Import CSV** (`ekkayi-products-import.csv`)

---

## 🛠️ Tech Stack
- **Framework**: React 18 + Vite
- **3D Engine**: Three.js (Dense Spherical Constellation, Stardust Particles, Orbit Controls)
- **Styling**: Vanilla CSS tokens & custom luxury utility system
- **Icons**: Lucide React + custom SVG brand marks
- **Shopify Theme**: Modern Liquid 2.0 Theme with real-time currency & cart integration

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```

### 3. Production Build
```bash
npm run build
```

---

## 📦 Shopify Theme & Catalog Import
- **Theme Archive**: Upload `ekkayi-shopify-theme.zip` under **Shopify Admin > Online Store > Themes > Add Theme > Upload zip file**.
- **Product CSV**: Import `ekkayi-products-import.csv` under **Shopify Admin > Products > Import**.
